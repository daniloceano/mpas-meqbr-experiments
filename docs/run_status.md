## What to do with a partial leg

Every analysis script takes `--experiments` and restricts itself to the time range common to the experiments being compared (`--common-period`, on by default). A partial EXP02 therefore shortens the comparison window for everyone rather than being compared over a different set of hours — which would confound the experiment difference with a difference in weather.

Re-run this script and then re-run the pipeline (`scripts/run_all.sh`) when a leg finishes.
